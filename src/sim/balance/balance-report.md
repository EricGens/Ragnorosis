Generated by `npm run balance` — do not edit by hand. Every battle is a real invasion run through the
game's combat code on plain ground (Defensibility 10, Stability 50), 40 seeds per matchup. Unless
noted, both sides have 6000 Production of filled units and the attacker arrives with Shock.
